# Model-Performance-Forecasting-Volatility-Between-INR-USD

## Data source

The notebook downloads daily Indian rupees per U.S. dollar spot exchange
rates from the Federal Reserve Board’s H.10 release via FRED
([DEXINUS](https://fred.stlouisfed.org/series/DEXINUS)).

The download covers January 1, 2010 through January 15, 2021. The
out-of-sample evaluation covers 2016–2020. January 2021 rates are used
only to complete the five-day volatility targets for the final
December 2020 forecast dates.
